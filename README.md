# 🇧 Bangladesh Macro-Financial Monitor
Live macro-financial dashboard for Bangladesh: inflation, GDP growth, BDT/USD, lending rates,
remittances and current account — plus a DSE bank valuation watchlist.

**Live app:** https://bd-macro-monitor.streamlit.app

## Stack
Python • Streamlit • Plotly • World Bank Open Data API • Streamlit Community Cloud
